## Employee Leave Management System

This is an assignment from my Mobile App Development class. Its not a big project, even the interface is simple. This simple app is made using Android Studio focusing only on 5 modules:

**Project Modules:**
1. Authentication Module (Login/Logout) - Controls system access and
differentiates user roles
2. Employee Management Module - Manages employee records in the system.
3. Leave Application Module - Allows employees to apply for leave.
4. Leave Approval Module - Enables admin to manage leave requests.
5. Leave History & Reporting Module - Tracks and displays leave records
